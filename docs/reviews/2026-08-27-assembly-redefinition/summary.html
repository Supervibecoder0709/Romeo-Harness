채택 확정 게이트는 이렇게 진행됩니다 — 당신이 고르기 전에는 아무것도 복사되지 않습니다

  1. 마일스톤 진입 시 후보표를 받습니다맡겨도 됨

    됐는지 확인: 아카이브(archive/<repo>/)에서 만든 파일 단위 표 — 채택 방식·켜는 조건·충돌 지점·라이선스가 행마다 있고, 30행 이하이며, 추천값이 기본 선택으로 채워져 있음 · 안 되면: 행에 충돌 지점이 비어 있으면 표가 미완성입니다

  2. 가져올 파일을 고릅니다당신이 정할 것

    됐는지 확인: 고른 파일마다 provenance/imports.yaml에 status: accepted·decided_at·source_sha가 기록됨 · 안 되면: 기록 없이 vendor/에 파일이 생겼다면 규약 위반(K-67)

  3. 원문 복사 또는 설치 프로브 + 어댑터 투영맡겨도 됨

    됐는지 확인: verbatim은 vendor/ 파일 해시가 원문과 같음(수정 0), install은 doctor가 존재·버전을 보고 · 안 되면: 해시 불일치 = 누군가 원문을 고친 것 → 롤백

  4. 부착 검증 — 두 런타임 discovery + 충돌 fixture 3종맡겨도 됨

    됐는지 확인: Claude·Codex 양쪽에서 스킬이 발견되고, T0 요청에 /plan만 뜨고, 자동 트리거 0, 경로·마커 충돌 0 · 안 되면: 실패한 파일만 rewrite 강등 또는 rejected. 게이트는 닫히지 않음

  5. 게이트 닫힘 — 이후 그 마일스톤의 부품 작업 시작

    됐는지 확인: 계획 §10 체크리스트 8b(G-M2)·13b(G-M3) 행이 관찰 가능한 근거와 함께 채워짐

게이트는 네 번입니다: G-M2 Superpowers(M2 첫 작업) · G-M3 BMAD/CIS(BMAD 본체 아카이브 선행) · G-M6 디자인 4종(UI 프로젝트가 생길 때) · G-M7 OpenWiki(v1 통과 후). 동등성 게이트(역할 교체 재현)는 그대로 있되, 부품이 켜진 상태에서 통과해야 합니다(D-58) — 부품 없이 증명하면 실제 사용 조건이 아니기 때문입니다.
