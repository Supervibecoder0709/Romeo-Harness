④ 만 먼저 해도 상태는 단조 개선이다 — 순환이 풀리고 문자열 약점은 그대로일 뿐 나빠지지 않는다.

**예산과의 충돌 하나.** §12 를 세우면 "정비 단위 최대 1개" 인데 위 항목은 그보다 많다.
그러나 Q-28~Q-31 은 정비가 아니라 **M3 본체 재작업**이다 — M3 가 세운 시나리오 3 의 차단이
아무것도 막지 못하고 있으므로 현재 마일스톤 수용 기준을 직접 막는다. 이 구분이 §12 의 첫 시험이 된다.

## 8. 검증 경계

- git 이력·작업 문서·attempts·세션 로그를 읽고, 라우터·승인·차단은 임시 저장소에서 **실제로 실행했다.**
- 저장소 코드와 문서는 이 파일 외에 수정하지 않았다.

- 여기서 제안한 문서 변경은 아직 **어떤 것도 반영되지 않았다.** 승인 전 제안이다.
- 검증 시점 CI 최신 성공은 `de3f758`. `29fdb6b` 의 CI 여부는 이 문서의 범위 밖이다.
