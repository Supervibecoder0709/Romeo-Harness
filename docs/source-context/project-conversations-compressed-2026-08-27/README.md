# Harness Engineering conversation export

Created: 2026-08-26T22:08:11Z

This bundle contains 25 project-linked local session records, one Markdown transcript per session, in chronological order.

## How to use it as harness context

Start with `INDEX.md`, then attach only the transcript files relevant to the decision or component you are working on. The full bundle is intentionally comprehensive, so pasting every file into one prompt will dilute the context window.

Each transcript preserves user and assistant messages plus observable tool calls/results. System/developer instructions, private model reasoning, and internal event bookkeeping are intentionally excluded. The source and exported checksums in `MANIFEST.json` and `SHA256SUMS` allow later integrity checks.
