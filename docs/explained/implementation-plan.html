지금 결정할 것 1/5 · 라이선스당신이 정할 것

지금 결정할 것 2/5 · 하네스가 전제하는 사용자당신이 정할 것

대가: 설명이 길어져 주의력 비용이 든다(정본이 첫 병목으로 지목한 것) · 되돌리려면: 원칙 문서 한 줄 수정, 쉬움.

지금 결정할 것 3/5 · 승인과 진행을 어떻게 구분할 것인가당신이 정할 것
문서의 승인 여부와 작업 진행을 별도의 상태 두 벌로 관리할 것인가(이번 요청), 정본대로 상태 하나(draft / active / done / dropped / superseded)만 둘 것인가(D-15)?

권고: 상태는 하나. "승인됨"은 approved_at(누가·언제)이라는 사실 필드로 기록하고, "검증됨"은 저장하지 않고 종료 판정 때 현재 HEAD와 비교해 계산한다. 요청한 구분을 만족하면서 정본 결정과 충돌하지 않는다.

대가: "검증됨"이 파일에 남지 않는다(볼 때마다 계산) · 되돌리려면: 문서 머리말 형식이라 나중에 바꾸면 모든 문서를 전수 수정해야 한다. 그래서 지금 정해야 한다.

지금 결정할 것 4/5 · Quick / Standard / Deep 이라는 이름당신이 정할 것
요청한 Quick/Standard/Deep 분류를 정본의 T0/T1/T2를 대체하는 이름으로 쓸 것인가?

대가: 이름이 두 벌 · 되돌리려면: 필드 하나, 쉬움.

지금 결정할 것 5/5 · v1이 다루는 프로젝트의 범위당신이 정할 것
