# 02. 동작 워크플로 요약

## 무엇을 하는가

이 패키지는 사람이 읽는 문자열을 slug, 즉 URL·파일명·식별자에 쓰기 쉬운 문자열로 바꾼다. 기본 API는 매 호출이 입력 문자열과 옵션에서 결과 문자열을 계산하며, `slugifyWithCounter()`는 같은 결과가 반복될 때 `-2`, `-3`처럼 번호를 붙이는 별도의 상태 있는 함수를 만든다. [S3], [S4]

## 입력

- `slugify(string, options?)`: 첫 인수는 반드시 JavaScript 문자열이다. 문자열이 아니면 즉시 `TypeError`를 던진다. [S4]
- 옵션 기본값은 `separator: '-'`, `lowercase: true`, `decamelize: true`, `customReplacements: []`, `preserveLeadingUnderscore: false`, `preserveTrailingDash: false`, `preserveCharacters: []`, `transliterate: true`다. `locale`은 기본 객체에 명시되지 않지만 타입 선언과 호출부에서 선택적으로 전달된다. [S4], [S6]
- `slugifyWithCounter()`는 인수 없이 새 카운터 인스턴스를 반환한다. 이후 그 반환 함수를 `slugify(string, options?)`처럼 호출하고 `reset()`으로 인스턴스 기록을 비운다. [S4], [S6]

## 처리 단계

1. **입력 검증 및 옵션 결합**: 문자열 타입이 아니면 중단하고, 제공된 옵션을 기본값 위에 덮어쓴다. 선행 `_`과 후행 `-` 보존 여부는 변환 전 원문에서 미리 기억한다. [S4]
2. **문자 치환·전사**: 기본값에서는 기본 치환 목록과 사용자가 준 `customReplacements`를 `Map`으로 합쳐 전사 라이브러리에 전달한다. 같은 키를 사용자가 제공하면 뒤쪽 항목이므로 기본값을 덮어쓴다. `transliterate: false`에서는 외부 전사를 건너뛰되, 사용자 정의 치환은 직접 적용한다. [S4], [S5]
3. **단어 경계와 대소문자**: `decamelize`가 참이면 camelCase·대문자 약어 경계를 공백으로 나누고, `lowercase`가 참이면 `locale`이 있을 때 locale-aware 소문자화, 없으면 일반 소문자화를 한다. [S4]
4. **허용 문자 규칙 구성**: 기본 허용 집합은 소문자 영문과 숫자다. 소문자화를 끄면 대문자도 추가하고, 전사를 끄면 유니코드 문자·숫자도 추가한다. `preserveCharacters`는 허용 집합에 더하지만 그 안에 구분자가 있으면 모호하므로 `Error`를 던진다. [S4]
5. **slug 정리**: 일부 축약·소유격의 아포스트로피를 제거하고, 허용되지 않은 연속 문자를 구분자로 바꾼다. 역슬래시는 제거한다. 구분자가 빈 문자열이 아니라면 연속 구분자를 하나로 줄이고 양끝 구분자를 없앤다. 마지막으로 1단계에서 기억한 `_`·`-`을 조건부로 복원한다. [S4]
6. **선택적 중복 번호 부여**: 카운터 인스턴스는 기본 slug 결과가 빈 문자열이면 빈 문자열을 바로 반환한다. 그렇지 않으면 소문자 키로 `Map`에 횟수를 기록하고, 중복 또는 번호가 붙은 기본 slug의 특정 조건에서는 새 번호 접미사를 붙인다. `reset()`은 이 `Map`을 비운다. [S4], [S7]

## 출력과 상태

- 기본 함수의 출력은 문자열 하나다. 파일, 데이터베이스, 네트워크에 결과를 저장하는 코드는 확인되지 않았다. [S4]
- 카운터 함수의 출력도 문자열이지만, 동일 인스턴스 안에서 이전 호출 결과에 따라 달라진다. 따라서 같은 인스턴스에서 재실행하면 결과가 달라질 수 있고, `reset()` 또는 새 인스턴스가 상태를 초기화한다. [S4], [S7]
- 패키지 export는 기본 함수와 이름 있는 `slugifyWithCounter`이며 TypeScript 타입도 함께 제공한다. [S3], [S6]

## 실패·재시도

확인된 실패는 두 종류다. 문자열 이외 입력은 `TypeError`, `preserveCharacters`에 `separator`와 같은 문자가 있으면 `Error`가 발생한다. 이 라이브러리 자체에는 네트워크 요청, 큐, 자동 재시도, 롤백이 없으므로 호출자는 예외를 처리하고, 상태 있는 카운터를 재실행할 때는 인스턴스 수명과 `reset()` 정책을 정해야 한다. [S4], [S7]

## 관찰 가능한 완료 증거

- 호출 직후 반환 문자열 또는 던져진 예외가 가장 직접적인 완료 증거다. [S4]
- 고정 커밋의 테스트는 일반 변환, 여러 언어 예시, 옵션, 카운터, 두 오류 조건을 AVA assertion으로 명시한다. [S7]
- CI 정의는 push와 pull request에서 Node 20·24 각각 `npm install` 후 `npm test`(`xo && ava`)를 실행한다. 다만 이 아카이브 작업은 원격 저장소를 clone·실행하지 않았으므로 해당 워크플로의 실제 실행 성공은 미검증이다. [S3], [S8]
