# 구성요소 문서 범위

이 저장소에는 `.rulesync/subagents/*.md` 5개와 `.rulesync/skills/*/SKILL.md` 42개가 있다. 이 디렉터리는 실제로 연 5개 서브에이전트 정의와 대표 skill 두 개의 한국어 번역을 담고, 실행 핵심은 [../04-components-table.md](../04-components-table.md)에 코드 근거로 정리한다. [S17]

42개 skill 전체의 이름·경로는 Git tree에서 확인했지만, `agent-team`과 배포용 `skills/rulesync/SKILL.md` 외 40개 정의의 전문·권한은 열람하지 않았다. 그러므로 이 아카이브는 그 40개 스킬의 세부 동작을 추정하지 않는다.
