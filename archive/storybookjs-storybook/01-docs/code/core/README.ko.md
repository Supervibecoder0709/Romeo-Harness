# Storybook

storybook package에는 Storybook의 core가 포함됩니다. 포함 항목은 다음과 같습니다.

- Storybook의 CLI와 개발 서버
- Storybook의 주 UI(일명 manager)
- 컴포넌트 control, toolbar control, action logging, viewport control, interaction debugger를 포함한 core 기능
- storybook/test, theming, viewport 같은 사용자용 utility library
- Storybook ecosystem의 framework, addon, builder가 사용하는 library

또한 CSF, MDX 및 Docs용 utility처럼 storybook/internal namespace 아래의 다양한 library와 utility도 포함합니다.

Storybook에 대해 더 알아보려면 [storybook.js.org](https://storybook.js.org/?ref=readme)를 방문하세요.
