## 경계 해석

- **확인:** 이 SHA에는 서버, DB, 인증 모듈, queue, API handler, 테스트, CI가 없다. [E01]
- **추론:** 그러므로 품질 검토의 실제 실행 주체·모델·파일 권한은 이 레포가 아니라 설치 대상 AI 도구/프로젝트 Harness가 결정한다. `command.md`가 프롬프트일 뿐 런타임 코드를 포함하지 않는 점이 근거다. [E04][E05]
- **미확인:** README가 가리키는 `web-design-guidelines` skill과 이 레포의 `command.md`가 동일한 내용을 어떤 방식으로 공유하는지는 별도 레포를 열지 않아 확인하지 않았다. [E12]
