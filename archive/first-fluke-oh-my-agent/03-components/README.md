# 구성요소 정의 번역 범위

이 디렉터리는 실행 경로를 대표하는 agent/skill 정의를 한국어로 옮긴 것이다. `pm-planner`, `qa-reviewer`, `architecture-reviewer`는 해당 정의 전체를 번역했고, `oma-orchestration`은 PM/Harness 판단에 필요한 scheduling·flow·guardrail·review/retry 계약 전체를 한국어로 옮겼다.

저장소에는 12개의 agent 정의와 36개의 skill root가 있으나, 나머지는 반복되는 전문 domain 정의 또는 resource tree라 이 archive에서 전문 번역하지 않았다. 그들은 **없음**이 아니라 “미열람/미번역”이며, product-level 역할 목록은 `01-docs/README.ko.md`와 `04-components-table.md`에서 확인할 수 있다. [E22]

원문 위치와 근거 상태는 `04-components-table.md`, line-level source links는 `06-source-evidence.md`를 기준으로 한다.
