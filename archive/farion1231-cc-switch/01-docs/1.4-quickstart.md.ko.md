# 1.4 빠른 시작

이 섹션은 5분 안에 초기 설정을 완료하도록 돕습니다.

## 1단계: 공급자 추가

1. 기본 인터페이스 오른쪽 위의 **+** 버튼을 클릭합니다.
2. "Preset" 드롭다운에서 공급자를 선택합니다.
   - 일반적인 preset: Zhipu GLM, MiniMax, DeepSeek, Kimi, PackyCode
   - 또는 수동 설정을 위해 "Custom"을 선택합니다.
3. **API Key**를 입력합니다.
4. "Add"를 클릭합니다.

![image-20260108002807657](../../assets/image-20260108002807657.png)

> **팁**: preset은 endpoint URL을 자동으로 채우므로 API Key만 입력하면 됩니다.

## 2단계: 공급자 전환

추가한 뒤 공급자가 목록에 표시됩니다.

**옵션 1: 기본 인터페이스에서 전환**
- 공급자 카드의 "Enable" 버튼을 클릭합니다.

**옵션 2: 시스템 트레이에서 빠르게 전환**
- 시스템 트레이의 CC Switch 아이콘을 마우스 오른쪽 버튼으로 클릭합니다.
- 공급자 이름을 직접 클릭합니다.

## 3단계: 활성화

공급자를 전환한 뒤 각 CLI 도구의 활성화 방식은 다릅니다.

| 애플리케이션 | 활성화 방법 |
|-------------|-------------------|
| Claude Code | 즉시 적용됨(hot reload 지원) |
| Codex | 터미널을 닫고 다시 열어야 함 |
| Gemini | 즉시 적용됨(각 요청에서 설정을 다시 읽음) |
| OpenCode | 터미널을 닫고 다시 열어야 함 |
| OpenClaw | 터미널을 닫고 다시 열어야 함 |

### Claude Code 첫 실행 프롬프트

Claude Code가 첫 실행 시 **log in**을 요청하거나 onboarding wizard를 표시하면 CC Switch에서 "Skip Claude Code first-run confirmation" 옵션을 활성화합니다.

1. CC Switch의 "Settings > General"을 엽니다.
2. "Skip Claude Code first-run confirmation" 토글을 켭니다.
3. Claude Code를 다시 시작합니다.

![image-20260108002626389](../../assets/image-20260108002626389.png)

> **참고**: 이 옵션은 공식 onboarding 흐름을 건너뛰도록 `~/.claude/settings.json`에 `skipIntroduction` 필드를 씁니다.

## 설정 확인

다시 시작한 뒤 해당 CLI 도구를 실행하고 간단한 질문을 입력해 테스트합니다.

```bash
# Claude Code - 실행 후 테스트 질문 입력
claude
> Hello, please briefly introduce yourself

# Codex - 실행 후 테스트 질문 입력
codex
> Hello, please briefly introduce yourself

# Gemini - 실행 후 테스트 질문 입력
gemini
> Hello, please briefly introduce yourself

# OpenCode - 실행 후 테스트 질문 입력
opencode
> Hello, please briefly introduce yourself

# OpenClaw - 실행 후 테스트 질문 입력
openclaw
> Hello, please briefly introduce yourself
```

AI가 정상적으로 응답하면 설정이 성공한 것입니다.

## 일반적인 문제

### 전환 뒤 적용되지 않나요?

터미널이나 CLI 도구를 다시 시작했는지 확인합니다. 설정 파일은 전환 시 업데이트되지만 실행 중인 프로그램은 자동으로 다시 로드하지 않습니다.

### preset을 찾을 수 없나요?

공급자가 preset 목록에 없으면 수동 설정을 위해 "Custom"을 선택합니다. 설정 형식 상세는 [공급자 추가](../2-providers/2.1-add.md)를 참고합니다.

### 공식 로그인을 복원하려면 어떻게 하나요?

"Official Login" preset(Claude/Codex) 또는 "Google Official" preset(Gemini)을 선택하고, 클라이언트를 다시 시작한 뒤 로그인 흐름을 따릅니다.
