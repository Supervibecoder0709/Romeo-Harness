이 저장소에 대한 기여는 [Software and Document License](https://www.w3.org/Consortium/Legal/copyright-software)의 적용을 받는 Technical Reports의 일부가 될 예정입니다. 문서에 실질적으로 기여하려면 관련 W3C Working Group에 참여하거나 저작권을 W3C로 이전해야 합니다.

기여(pull request)에 본인 외의 기여자가 있다면 pull request 댓글에서 모든 기여자를 밝혀야 합니다.

기여자(본인 외; 본인은 자동으로 추가됨)를 추가하려면 한 줄에 한 명씩 다음과 같이 표시하세요.

```
+@github_username
```

실수로 기여자를 추가했다면 댓글에서 다음과 같이 제거할 수 있습니다.

```
-@github_username
```

다른 사람을 대신하여 pull request를 만들었지만 기능 설계에 참여하지 않았다면 위 문법으로 자신을 제거할 수 있습니다.
