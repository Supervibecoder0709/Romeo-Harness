## CIS 소개

Creative Intelligence Suite(CIS)는 아이디어가 태어나고, 문제가 재구성되고, 구조화된 창의성으로 solution이 떠오르는 개발의 모호한 초기 단계를 위한 도구로 BMad Method를 확장합니다.

## 포함된 모듈

| Agent/Workflow | 목적 |
|---------------|---------|
| **Innovation Strategist** | disruption opportunity와 business model innovation 식별 |
| **Design Thinking Coach** | 공감, ideation, prototyping을 통한 인간 중심 설계 |
| **Brainstorming Coach** | 검증된 기법으로 창의적 ideation session 진행 |
| **Problem Solver** | 체계적 문제 진단과 root cause 분석 |
| **Creative Problem Solver** | lateral thinking으로 창의적 solution 생성 |
| **Storyteller** | 제품과 기능을 위한 설득력 있는 narrative 제작 |
| **Presentation Master** | 설득력 있는 presentation 구성과 전달 |

## 설치

CIS는 BMad Method 설정 중 module로 설치합니다.

```bash
npx bmad-method@alpha install
```

module 목록에서 **Creative Intelligence Suite**를 선택합니다.

## 빠른 시작

BMad Method를 CIS와 함께 설치한 뒤 다음 workflow를 시도해 보세요.

```
/cis-brainstorm      # 구조화된 기법으로 idea 생성
/cis-design-thinking # 인간 중심 design process
/cis-problem-solve   # 체계적 문제 분석
/cis-innovation      # business model과 disruption 분석
```

## CIS를 사용할 때

| 상황 | 사용 대상 |
|-----------|----------|
| 문제에 막혔을 때 | `/cis-problem-solve` |
| 새로운 idea가 필요할 때 | `/cis-brainstorm` |
| 사용자를 위한 설계를 할 때 | `/cis-design-thinking` |
| 시장 공백을 찾을 때 | `/cis-innovation` |
| 제품 story를 전할 때 | `/cis-storytelling` |
| pitch를 준비할 때 | `/cis-presentation` |

## 예시: 브레인스토밍 session

```
You: /cis-brainstorm
CIS: 무엇을 브레인스토밍하고 싶으신가요?
You: 사용자 onboarding을 개선할 방법
CIS: SCAMPER 기법을 사용해 봅시다...
    [7개의 창의적 관점으로 안내]
    [다양하고 실행 가능한 idea 생성]
```

## Workflow 기능

- **Idea Generation** — SCAMPER, Reverse Brainstorming 등의 여러 ideation framework
- **Problem Reframing** — 장애물을 기회로 전환
- **User Empathy** — 사용자 필요에 대한 깊은 이해 형성
- **Solution Divergence** — 수렴하기 전에 많은 option 생성
- **Narrative Craft** — 제품의 story 만들기

## 팀 협업

CIS에는 협업적 창의성을 위한 team configuration이 포함됩니다.

- **Creative Squad** — cross-functional creative session
- **Design Pair** — 2인 design thinking
