## 근거 해석 규칙

- **확인됨:** 위 파일·줄에서 직접 읽은 선언 또는 코드 동작이다.
- **설정 확인:** manifest/지침에 적힌 구성이다. 실제 설치·실행 성공을 뜻하지 않는다.
- **실행 미검증:** 이 작업은 GitHub 읽기 전용 분석이므로, script의 실제 실행·외부 서비스 반응·산출물 품질은 확인하지 않았다.
